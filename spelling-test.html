Microphone needs HTTPS

Browsers only allow microphone access on secure pages. The easiest fix is a free GitHub Pages site.

One-time setup (5 minutes):
1. Go to github.com and create a free account
2. Create a new repository, tick Add README
3. Upload spelling-test.html to the repo
4. Go to Settings → Pages → Branch: main → Save
5. Your URL will be:
https://YOUR-USERNAME.github.io/REPO-NAME/spelling-test.html

Or run locally: python3 -m http.server 8000 then open localhost:8000/spelling-test.html in Chrome
